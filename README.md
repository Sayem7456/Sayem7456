## 🔬 Research

**Under review**
- **ACAT-UE**: Uncertainty-aware cross-modal co-attention fusion of CT and histopathology for lung cancer classification. *Expert Systems with Applications (Elsevier).* Acc 92.78%, macro-AUC 0.968, ECE 0.079.
- **GDDI**: Gradient-decoupled dual-stream learning for edge-efficient melanoma classification (~2M params). *Journal of Visual Communication and Image Representation (Elsevier).* AUC-ROC 0.898 on ISIC 2020.

**In preparation / ongoing**
- **BS-Net**: Curriculum-guided spatial attention supervised by clinical bounding-box priors to curb shortcut learning in multi-label chest X-ray screening (macro-AUC 0.961, Pointing Game 84.9%).
- **CausalMask-XAI**: Intervention-based evaluation of explanation faithfulness in breast ultrasound classification, with external validation on BUS-UCLM.

**Published**
- Channel attention in hybrid deep learning for brain tumor MRI classification · *Springer ICDSAIA 2025*
- Predicting physical movement intensity of elderly people from low-cost gas sensors · *IEEE ICEEICT 2024*
- AFRA: adaptive ML for electrical fault detection and minimization · *IEEE ICICT 2024*
- Passenger request trends and ride-sharing system performance · *CRC Press book chapter, 2025*
